Gooscript / Shark Tools package snapshot

This folder is an unpacked browser-extension snapshot. It currently has the same manifest and background script as gooextension/final, but its content/settings files differ. It is not generated by the maintained build script and will not update when gooextension/final changes.

For the maintained source and release workflow, use:
  gooextension/final/
  gooextension/final/build-extensions.ps1

To try this snapshot locally:
1. Open chrome://extensions/ (or the equivalent Chromium extensions page).
2. Enable Developer mode.
3. Choose Load unpacked and select this Gooscript/ folder.
4. Review the requested extension permissions before enabling it.

Do not install both this snapshot and the maintained Shark Tools build at the same time unless you intend to run two separate copies.
